# VynAsk Landing Page

Static landing page (HTML, CSS, JavaScript). No build step.

## Open in VS Code
1. File > Open Folder... and choose the `VynAsk` folder.
2. Install the recommended extension **Live Server**.
3. Right-click `index.html` > **Open with Live Server**.

## Structure
- `index.html`  page content (English text plus `data-zh` Chinese text)
- `styles.css`  theme colours (Presoft SOP palette), layout, animations
- `script.js`   EN/中文 toggle, scroll reveal, video player, Why VynAsk carousel, WhatsApp bubble (after 5s)
- `assets/`     Presoft logo, VynAsk icon, icon pack (`assets/icons/*.webp`), feature screenshots (`assets/features/*.webp`, spare charts in `assets/features/more-charts/`), your demo video (`assets/demo.mp4`)
